# Язык C++17, Qt 6 и система сборки CMake

## Контекст и постановка задачи

По SRS 0.1 «UtilitySmart» — десктопное приложение, работающее локально без серверной части. Нужно выбрать язык, GUI-фреймворк и систему сборки, которые позволят одному разработчику реализовать проект за 12 недель и собрать portable-версию. Детали хранения данных и выбора GUI-подхода вынесены в ADR-0002 и ADR-0004.

## Драйверы решения

* Десктопная поставка без серверной части — REQ-INST-001.
* Локальная работа и отсутствие сетевых зависимостей — REQ-SEC-001.
* Сборка через CMake — REQ-BUILD-001.
* Приемлемая скорость разработки одним исполнителем.

## Рассмотренные варианты

* C++17 + Qt 6 + CMake
* C# + WPF + MSBuild
* Python + PyQt + setuptools

## Итог решения

Выбранный вариант: «C++17 + Qt 6 + CMake», потому что он соответствует ограничениям SRS, даёт нативное десктопное приложение и не требует установки дополнительной серверной среды. C# привязал бы проект к Windows, Python уступает в скорости запуска и усложняет portable-поставку.

### Последствия

* Хорошо, потому что приложение собирается в один portable-каталог.
* Хорошо, потому что Qt 6 поддерживает Windows и Linux.
* Плохо, потому что при поставке нужно копировать DLL Qt.
* Плохо, потому что C++ требует более внимательной работы с памятью, чем C# или Python.

### Подтверждение

* Локальная сборка через CMake на чистой Windows 10.
* Запуск собранного приложения без установки дополнительных компонентов.

## Плюсы и минусы вариантов

### C++17 + Qt 6 + CMake

* Хорошо, потому что соответствует REQ-BUILD-001 и REQ-INST-001.
* Хорошо, потому что даёт нативную производительность.
* Плохо, потому что требуется поставлять DLL Qt.

### C# + WPF + MSBuild

* Хорошо, потому что быстрая разработка форм.
* Плохо, потому что привязывает проект к Windows.
* Плохо, потому что требует .NET Runtime.

### Python + PyQt + setuptools

* Хорошо, потому что простой синтаксис.
* Плохо, потому что медленный запуск и сложнее portable-сборка.
* Плохо, потому что требуется интерпретатор или упаковщик.

## Дополнительная информация

Связанные требования: REQ-BUILD-001, REQ-INST-001, REQ-SEC-001.  
Связанные решения: ADR-0002, ADR-0004.
